# Código de conducta

Este repositorio de capacitación busca un ambiente profesional, inclusivo y respetuoso. Se espera que las personas participantes usen lenguaje apropiado, acepten retroalimentación constructiva y colaboren de buena fe.

No se toleran ataques personales, acoso, publicación de información sensible ni conducta que dificulte el aprendizaje. Los incidentes deben reportarse al equipo instructor ficticio para revisión y acciones proporcionales.
