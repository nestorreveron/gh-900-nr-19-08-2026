# Contribuir

1. Haz fork del repositorio si trabajas fuera de la organización.
2. Crea una branch descriptiva: `git switch -c feature/customer-search`.
3. Realiza commits pequeños con Conventional Commits, por ejemplo `feat: add customer search`.
4. Ejecuta `ruff check .` y `pytest -q`.
5. Abre un pull request, vincula un Issue y completa la plantilla.
6. Participa en la revisión con respeto, responde comentarios y solicita aprobación.
7. El merge debe seguir GitHub Flow: branch corta, PR revisado y checks en verde.
