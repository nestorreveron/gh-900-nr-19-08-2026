# Guía del instructor

Usa este repositorio como hilo conductor del curso GH-900. Antes de iniciar, ejecuta `python scripts/demo_setup.py`, `ruff check .` y `pytest -q`. Marca claramente qué características dependen de permisos, licenciamiento o configuración del repositorio.

Secuencia sugerida: repositorio, commits, branches, Issues, PRs, Actions, Copilot, seguridad, Projects y releases.
