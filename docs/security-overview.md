# Seguridad conceptual

- Dependabot detecta dependencias con actualizaciones disponibles.
- Dependency graph muestra relaciones de paquetes cuando está habilitado.
- CodeQL analiza patrones de vulnerabilidad en código.
- Secret scanning detecta secretos conocidos y push protection puede bloquear commits con credenciales.
- No uses secretos reales en demos; usa solo `DEMO_SECRET_DO_NOT_USE` como marcador educativo.
