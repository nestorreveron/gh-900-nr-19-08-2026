# Requisitos

## Funcionales

- Gestionar clientes, productos, órdenes y tickets.
- Buscar clientes por nombre, país, industria o correo.
- Mostrar métricas básicas de negocio.
- Exponer una interfaz web simple y endpoints JSON.

## No funcionales

- Python 3.12, Flask, SQLite y SQLAlchemy.
- Datos ficticios reproducibles.
- Sin secretos ni servicios de pago.
- Fácil de ejecutar en local y Codespaces.
